MAPLE-K

MAPLE-K is a C++ library for monitoring robotic safety constraints in joint and Cartesian spaces. The host application provides measurements, constraint configuration, and robot-specific callbacks.

Features

  • Joint Space Analysis: Monitors joint-level parameters (torque, temperature, angular velocity/acceleration, power) using CUSUM-based detection.
  • Cartesian Space Analysis: Evaluates TCP (Tool Center Point) forces, torques, velocities, and accelerations across defined spatial zones.
  • Zone-Based Constraints: Supports multiple Cartesian zones (free, expected, in-contact, past-contact) with customizable constraints.
  • XML Configuration: Easily configurable constraints via XML files.
  • Periodic Analysis Loop: Receives measurements from the host application and checks configured constraints.
  • Offline Recovery Planning and Execution: APLE scores candidate action sequences with a host-provided simulator, selects a recovery plan, and invokes the host's execution callback, applying any required constraint relaxation for the duration of execution.

Dependencies

  • C++23-capable compiler
  • CMake 3.28 or newer
  • Eigen3
  • Boost filesystem, system, thread, and chrono libraries

Tests fetch Catch2 when BUILD_TEST=ON. Building API documentation with BUILD_DOCUMENTATION=ON requires Doxygen.

Build and Install

Debian/Ubuntu helper

The helper installs Boost and Eigen3 with apt, builds MAPLE-K in Release mode, and installs to the system prefix with sudo:

git clone https://github.com/teknologisk-institut/MAPLE-K.git
cd MAPLE-K
./setup_and_install.sh

Manual build

After installing the dependencies listed above:

git clone https://github.com/teknologisk-institut/MAPLE-K.git
cd MAPLE-K
cmake -S . -B build
cmake --build build --target MAPLE_K
cmake --install build --prefix "$HOME/.local"

Public API and Upgrading

The installed public headers are MAL.hpp, Measurement.hpp, Offline/APLE.hpp, Error.hpp, Analyse_Flags.hpp, ConstraintRelaxation.hpp, and Offline/RecoveryStrategy.hpp. The list is maintained in include/CMakeLists.txt.

Link an installed package with the exported MAPLE_K::MAPLE_K target. For the manual installation above, configure the consumer with -DMAPLE_K_DIR="$HOME/.local/lib/MAPLE_K-1.0".

Continue to use APLE<YourActionEnum> and Recovery::Action<T> / Recovery::Plan<T>; direct use of planner and evaluator implementation types is unsupported. Rebuild downstream applications after upgrading, and use a clean install prefix because CMake does not remove private headers left by older installations.

See the installed consumer for a package-use example and tests/README.md for test commands.

Usage Example

The recovery planner uses host-provided simulation scoring, simulator-state loading, and action execution callbacks. Configure MAL with constraints and callbacks before using it for online monitoring; APLE uses it as the constraint-relaxation interface during recovery. Lower aggregate scores rank better.

In the consuming application's CMakeLists.txt, find and link the installed package:

cmake_minimum_required(VERSION 3.28)
project(RobotApplication LANGUAGES CXX)
find_package(MAPLE_K CONFIG REQUIRED)
add_executable(robot_app main.cpp)
target_compile_features(robot_app PRIVATE cxx_std_23)
target_link_libraries(robot_app PRIVATE MAPLE_K::MAPLE_K)

For the manual install above, configure the consumer with -DMAPLE_K_DIR="$HOME/.local/lib/MAPLE_K-1.0".

#include <MAL.hpp>
#include <Offline/APLE.hpp>
#include <functional>
#include <stdexcept>
#include <string>
#include <vector>
enum class RobotAction { Linear, Joint, MotionDelta, Failed };
using Actions = std::vector<Offline::Recovery::Action<RobotAction>>;
void recover(MAL &monitor,
std::function<double(const Actions &)> simulate,
std::function<void(std::string)> load_state,
std::function<bool(const Actions &)> execute,
const std::string &error_log,
const std::string &environment_state)
{
Offline::APLE<RobotAction> planner("recovery-data", simulate, load_state);
planner.set_action_space(RobotAction::Linear, RobotAction::Joint, RobotAction::MotionDelta);
const auto plan = planner.get_solution(RobotAction::Failed, error_log, environment_state, monitor);
if (!planner.execute_mitigation(execute, plan, monitor))
{
throw std::runtime_error("Recovery execution failed");
}
}
