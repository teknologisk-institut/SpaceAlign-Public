Detailed Description

◆ set_log_saved_trigger()

void MAL::set_log_saved_trigger ( function< void()>  callback)

Function handle invoked when an automatic failure log has been completed. It is called synchronously from the MAL loop thread, after stop_signal has run and after the error-log XML entry has been written, flushed and closed, so the file is complete and safe for the host to read (e.g. via Offline::read_latest_err_log). It is not called for user-requested save(), or if writing the log failed. Passing an empty callback clears the registration.

Parameters
callbackFunction notified that the automatic failure log is ready.
